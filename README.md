# Vietnam Itinerary

Single-page static travel guide for two families' Vietnam trip (15 Nov – 1 Dec) — prerequisites,
essential apps, and destination guides (hotels, places, restaurants) for Hà Nội, Sa Pa, and
Phú Quốc, where both families' separate itineraries converge. Romanian by default, with an
English toggle.

Source content comes from a shared Google Doc the families maintain; this site is the polished,
link-rich published view of it — it is not auto-synced, so re-publish `index.html` after the Doc
changes meaningfully.
